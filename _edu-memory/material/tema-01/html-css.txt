HTML

HyperText Markup Language (Lenguaje de marcado de hipertexto)

Marcado: porque usa marcas para etiquetar contenido.

Hipertexto: hace referencia a los vínculos (enlaces) entre contenidos.

Nos permite definir la estructura de una página web.

● Estructura: párrafos, headings, tablas, listas, etc.
● Contenido: textos, imágenes, links

HTML: ejemplo

<!DOCTYPE html>
<html lang="es">
<head>
    <meta charset="UTF-8">
    <title>Un título</title>
</head>
<body>
    <p>Un párrafo</p>
</body>
</html>

CSS: tipos de selectores

Tipos de selectores:

● De elemento: h1, p, div, span, etc. h1 {color: black;}
● De identificador: a través de la propiedad “id” en los elementos HTML. 

#titulo {color: blue;}

● De clase: a través de la propiedad "class" en los elementos HTML. 

.libros {color: green;}

Stylesheets

Es un archivo que contiene el código CSS que describe estilos y puede ser 
importado por uno o más documentos HTML.

<head>

  <title>Un título</title>

  <!-- ... -->

  <link href="path-to-stylesheet/stylesheet.css" rel="stylesheet">

  <!-- ... -->

</head>

Actividad

Basándonos en la actividad de HTML y usando CSS realizar las siguientes tareas 
agregando un stylesheet:

● Que todos los elementos <li> tengan color rojo
● Que el segundo elemento <li> esté en negrita
● Que tanto el tercer <li> como el <p> tengan un tamaño de letra distinto a los 

demás elementos y que además estén subrayados

Bootstrap

Es un framework frontend que provee CSS ya estructurado para incluir en 
documentos HTML.

● Simplifica el estilo para webs complejas
● Provee maneras de adaptar a distintos tamaños de pantalla
● Reduce la frustración de usar CSS plano, ya que no se requiere ser experto 

en este lenguaje para usar el framework
