Introducción a HTML & CSS 
Fecha de entrega: Martes 31/3 20 hs 

Enunciado 

Dominio: Desarrollar una página web de un blog personal usando HTML5, CSS3 y 
Bootstrap 5. 

¿Por qué es relevante? Toda aplicación web comienza con una interfaz HTML/CSS bien 
estructurada. Bootstrap es uno de los estándares de la industria para prototipado rápido y 
responsive design. Más adelante lo usaremos en las vistas Django para el trabajo 
integrador. 

¿Qué van a construir? 

Un sitio de blog con: 

●  Página de inicio (listado de artículos en tarjetas Bootstrap) 
●  Página "Acerca de mí" (sección personal con foto) 
●  Formulario de contacto (validación HTML5 + CSS de feedback) 
●  Barra de navegación responsiva (Navbar de Bootstrap) 
●  Footer con redes sociales 
●  Diseño mobile-first (media queries, Bootstrap grid)

Criterios de Aceptación 

✅ HTML válido (sin errores W3C) 
✅ Todas las páginas funcionan (sin 404) 
✅ Formulario valida y muestra feedback 
✅ Navbar responsiva funciona en mobile/desktop 
✅ Bootstrap se usa apropiadamente (no DIVs personalizados para cosas que ya hace 
Bootstrap) 
✅ CSS limpio, sin duplicación 
✅ README con instrucciones (cómo abrir, navegación, validar) 
✅ Commits significativos en Git (≥5 commits, mensajes claros) 

REQUISITOS TÉCNICOS 

ESTRUCTURA: 

- index.html → página de inicio (listado de artículos) 
-  about.html → página "Acerca de mí" 
-  contact.html → formulario de contacto 
-  assets/styles.css → estilos personalizados 
-  assets/images/ → fotos (favicon, avatar, artículos) 
-  README.md → documentación 

HTML: 

-  DOCTYPE, meta charset, viewport en todas las páginas 
-  Navbar con logo, links activos, menú colapsable (Bootstrap) 
-  Breadcrumbs (opcional, suma puntos) 
-  Tarjetas de artículos (Bootstrap card component) 
-  Formulario con fieldset, labels, inputs con tipos correctos 
-  Footer sticky o al final de la página 
-  Favicon linked en <head> 

CSS: 

-  Colores y tipografía personalizados (no defaults de Bootstrap)

-  Media queries para mobile (<768px) y desktop (≥768px) 
-  Transiciones suaves en botones/links 
-  Feedback visual en formulario (color rojo para :invalid, verde para :valid) 
-  Clases BEM o similar (nada de #id salvo única excepciones) 

BOOTSTRAP: 

-  Navbar (navbar, navbar-brand, nav-link, navbar-toggler) 
-  Grid system (row, col-md-4, etc.) 
-  Card component (para artículos) 
-  Form controls (form-control, form-check, etc.) 
-  Buttons (btn, btn-primary, btn-sm, etc.) 
-  Utilities (spacing, colors, text alignment) 

FORMULARIO: 

-  Campo nombre (text, required) 
-  Campo email (email, required) 
-  Campo teléfono (tel, opcional) 
-  Campo mensaje (textarea, required, minlength=10) 
-  Botón submit 
-  Validación HTML5 (sin JavaScript) 
-  Styles :valid/:invalid en CSS 
-  Label asociado a cada input (for/id)
