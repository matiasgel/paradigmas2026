## Contenidos Mínimos Obligatorios

Según el programa oficial (sección 4 — Programa Analítico), los **7 módulos** de dictado obligatorio son:

---

### MÓDULO I — Diseño y construcción de aplicaciones en entornos de desarrollo ágil
**Semanas: 1–2 (12 hs)**

Tópicos mínimos obligatorios:
- El Modelo Ágil para construcción de aplicaciones
- Herramientas de desarrollo ágil
- Entornos de desarrollo integrado (IDE)
- Código autodocumentado y herramientas de extracción de código
- Construcción de aplicaciones en entornos de desarrollo integrado
- Pautas y criterios para la transformación diseño-código
- Lenguajes dinámicos para desarrollo de aplicaciones
- **Introducción al lenguaje Python** (sintaxis, tipos, funciones, colecciones)

---

### MÓDULO II — Pruebas Unitarias
**Semanas: 3–4 (12 hs)**

Tópicos mínimos obligatorios:
- Importancia de la detección oportuna de errores
- Clasificación y tipos de pruebas
- Prueba de Unidad: definición y propósito
- Procedimiento para pruebas de unidad
- **Soporte del lenguaje Python para pruebas de unidad** (unittest, pytest)

---

### MÓDULO III — Lenguajes y Frameworks para desarrollo de aplicaciones WEB
**Semana: 5 (parcial, 6 hs — compartida con Módulo IV)**

Tópicos mínimos obligatorios:
- Características de aplicaciones WEB
- Capas y arquitectura de una aplicación WEB
- Diseño de la aplicación web
- **El patrón MVC**
- Concepto de Framework como ambiente de trabajo
- Importancia del uso de frameworks para desarrollo rápido
- Frameworks MVC para desarrollo WEB
- **Introducción al Framework Django**
- **Introducción a Git**

---

### MÓDULO IV — Manejo de Persistencia
**Semanas: 5–6 (parcial + completo, aprox. 9 hs)**

Tópicos mínimos obligatorios:
- Concepto de persistencia
- Persistencia y su relación con los lenguajes de programación
- Soluciones al problema de la persistencia en Python
- **Mapeo OO–Relacional**
- Comparación de tecnologías ORM (Object Relational Mapping)
- **Persistencia en Django**
- Mapeo de entidades y relaciones en Django
- **Operaciones CRUD con Django**
- Consultas dinámicas en Django

---

### MÓDULO V — Desarrollo de interfaces de usuario utilizando el patrón MVC
**Semanas: 7–10 (24 hs)**

Tópicos mínimos obligatorios:
- Las vistas y templates de Django como parte del patrón MVC
- Vistas genéricas de Django
- El lenguaje de templates de Django
- **Modelado de interfaz de usuario con Django y HTML5**
- Formularios de Django
- Vistas y validaciones de formularios

---

### MÓDULO VI — Autorización y Autenticación
**Semanas: 11–14 (24 hs)**

Tópicos mínimos obligatorios:
- Sesiones de usuario en aplicaciones web
- **Manejo de autenticación en Django**
- Vistas genéricas para manejo de usuario y formularios
- Desarrollo de templates para manejo de usuarios
- **Autorización en Django**: permisos en modelos y vistas
- Generación de interfaz de administrador con manejo de permisos

---

### MÓDULO VII — Desarrollo de servicios con Django
**Semana: 15 (6 hs)**

Tópicos mínimos obligatorios:
- **Introducción al desarrollo y consumo de servicios WEB con Django**
