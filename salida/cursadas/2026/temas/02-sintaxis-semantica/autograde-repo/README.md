# TP 02 — Sintaxis y Semántica de Lenguajes (Autograding)

Este repo es la plantilla para la entrega automática del TP. El objetivo es evaluar la comprensión de conceptos de gramáticas, derivaciones, ambigüedad y estructuras de lenguaje.

## Qué tenés que hacer

1. Implementá las funciones en `src/index.ts`.
2. Coré los tests localmente con:

```bash
npm install
npm test
```

3. Hacé commit y push al repositorio de entrega.

---

## Cobertura de temas

Este TP cubre:

- Análisis de gramáticas y derivaciones.
- Representación de árboles sintácticos.
- Detección de ambigüedad en gramáticas.
- Construcción de una EBNF equivalente.

Los tests definen la cobertura mínima esperada.
