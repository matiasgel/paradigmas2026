# TP 01 — Conceptos Introductorios (Autograding)

Este repo es la plantilla para la entrega automática del TP. Está diseñado para que el alumno entregue código que demuestre comprensión de los conceptos vistos en clase (tipos, compilación, errores comunes, etc.).

## Qué tenés que hacer

1. Implementá las funciones en `src/index.ts`.
2. Coré los tests localmente con:

```bash
npm install
npm test
```

3. Hacé commit y push al repositorio de entrega.

---

## Cobertura de temas

Este TP pide demostrar comprensión de:

- Tipos en TypeScript y cómo el sistema evita errores (tipado estático).
- El pipeline de compilación de TypeScript (`.ts` → `.js`).
- Distinción entre errores de compilación y errores de ejecución.
- Lectura y manipulación básica de estructuras de datos.

Los tests definen la cobertura mínima que debe cumplirse.
