## Notas para el Docente

1. Las preguntas están diseñadas para nivel de 4° año — requieren análisis, no memorización
2. Los distractores son plausibles y atacan misconceptions comunes
3. Las preguntas de código requieren trazar ejecución o identificar propiedades
4. Se recomienda activar shuffle de opciones en Moodle para reducir copia
5. El tiempo estimado es ~1.5 min/pregunta — ajustar según cohorte
6. Las preguntas Q43–Q56 son las más exigentes (código + análisis)
