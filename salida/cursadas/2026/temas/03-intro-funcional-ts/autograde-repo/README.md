# TP 03 — Introducción a Programación Funcional con TypeScript (Autograding)

Este repo es la plantilla para la entrega automática del TP. Cuando crees un **nuevo repositorio de entrega** (GitHub Classroom / GitHub Codespaces), debe contener los archivos de este repo.

## Qué tenés que hacer

1. Implementá lo pedido en `src/index.ts`.
2. Coré los tests localmente con:

```bash
npm install
npm test
```

3. Hacé commit y push al repositorio de entrega.

---

## Estructura

- `src/index.ts` — Código para completar.
- `__tests__/index.test.ts` — Pruebas que se ejecutan en el pipeline.
- `package.json` + `tsconfig.json` — Configuración de TypeScript y Jest.
- `.github/workflows/ci.yml` — Pipeline de CI que corre los tests.
