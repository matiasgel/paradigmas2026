Formato GIFT con medios
Tipo Question format, Gift with medias format
Conjunto N/A
Descargas https://moodle.org/plugins/qformat_giftmedia
Problemas https://tracker.moodle.org/issues/?jql=project%20%3D%20CONTRIB%20AND%20component%20%3D%20%22Question+format%3A+Gift+media%22
Discusión https://moodle.org/mod/forum/discuss.php?d=170493
Mantenedor(es) Jean-Michel Vedrine

GIFT con medios es un plugin de Moodle que permite importar preguntas escritas con la misma sintaxis usada por el Formato GIFT, pero en lugar de un archivo de texto, importa un archivo ZIP que contiene el archivo de texto GIFT y los archivos de medios (imágenes, sonidos, ...);.

Características

Este es un plugin contribuído por terceros, por lo que debe instalarse de forma separada a Moodle y está disponible para descarga en el Moodle Plugins Directory que se encuentra en GIFT with media import format.

Una manera de comprender como preparar sus preguntas que serán importadas usando este formato es ver el archivo de ejemplo incluido que encontrará en question/format/giftmedia/giftmedia_example.zip. Este es un archivo ZIP, por lo que, si lo abre/descomprime encontrará:

  • Un archivo de texto llamado giftmediaexample.txt escrito empleando la sintaxis GIFT
  • Una subcarpeta de imágenes con cuatro imágenes: 93px-Zuckermann_ZBox_harpsichord.JPG, 99px-SMV_organ.jpg, 120px-MIM_Clavichord_CN344.jpg y 120px-Perzina_pianos.JPG
  • Una subcarpeta de sonidos con solamente un archivo piano.mp3 (¡por favor tome nota de que en una pregunta real para estudiantes esto sería un mal nombre porque les daría una clave acerca de la respuesta correcta !)

El contenido del archivo giftmediaexample.txt es //This is a simple MC question linked to a single MP3 file which is included in the archive.

MC question with images and an MP3 file::

Listen to this<a href\="@@PLUGINFILE@@/sounds/piano.mp3">:</a>
What is it? {=<img style\="vertical-align: middle; margin: 10px;" src\="@@PLUGINFILE@@/images/120px-Perzina_pianos.JPG" alt\="a piano" />a piano ~<img style\="vertical-align: middle; margin: 10px;" src\="@@PLUGINFILE@@/images/93px-Zuckermann_ZBox_harpsichord.JPG" alt\="a harpsichord" />a harpsichord ~<img style\="vertical-align: middle; margin: 10px;" src\="@@PLUGINFILE@@/images/99px-SMV_organ.jpg" alt\="an organ" />an organ ~<img style\="vertical-align: middle; margin: 10px;" src\="@@PLUGINFILE@@/images/120px-MIM_Clavichord_CN344.jpg" alt\="a clavichord" />a clavichord} Usted puede reconocer una pregunta que usa la sintaxis GIFT, y puede ver como es que están incluidos el archivo de sonido y las imágenes: la palabra especial @@PLUGINFILE@@ está añadida al principio de la ruta hacia el archivo.

Si Usted importa este archivo ZIP a su Banco de preguntas (lo cual tambien funciona para una Lección) Usted obtendrá un Tipo de Pregunta de Opción Múltiple que se mostrará como:

Como Usted puede ver, el enlace hacia el archivo de sonido ha sido remplazado por un reproductor de medios y las imágenes son mostradas.


Sugerencias

Actualmente el archivo de texto que contiene las preguntas debe de estar al nivel de raíz del archivo ZIP, y debe de tener una extensión.txt para que sea encontrado y procesado correctamente.

No se olvide que en la sintaxis GIFT el caracter `=` es un caracter especial, por lo que cada `=` en su HTML tiene que ser escrito como `\=` (vea el ejemplo de arriba). Es muy fácil cometer este error y después estar confundido poque sus preguntas no fueron importadas, por lo que Usted ha sido advertido.

No se olvide que el archivo de texto GIFT debe de estar correctamente codificado en UTF-8.
