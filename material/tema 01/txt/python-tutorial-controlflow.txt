4.1 SENTENCIA IF
-----------------
  >>> if x < 0:
  ...     x = 0
  ... elif x == 0:
  ...     print('Zero')
  ... else:
  ...     print('More')

- Cero o más elif; else opcional.
- elif evita indentación excesiva (equivale a switch/case de otros lenguajes).

4.2 SENTENCIA FOR
------------------
Itera sobre items de cualquier SECUENCIA (lista, string) en orden de aparición.
  >>> for w in words:
  ...     print(w, len(w))

Si necesitás modificar la colección mientras iterás → iterar sobre una COPIA:
  for user, status in users.copy().items():

4.3 FUNCIÓN RANGE()
-------------------
Genera progresiones aritméticas:
  range(5)        → 0,1,2,3,4
  range(5, 10)    → 5,6,7,8,9
  range(0, 10, 3) → 0,3,6,9   (step)
  range(-10, -100, -30) → negativos

range() retorna un objeto ITERABLE (no una lista) — eficiente en memoria.
Combinado con enumerate() para obtener índice + valor.

4.4 BREAK Y CONTINUE
---------------------
break: termina el bucle for/while más interno.
continue: continúa con la siguiente iteración.

4.5 CLÁUSULA ELSE EN BUCLES
-----------------------------
Se ejecuta si el bucle terminó SIN break. Muy útil para búsquedas:
  for n in range(2, 10):
      for x in range(2, n):
          if n % x == 0:
              break
      else:
          print(n, 'es primo')  # solo si no hubo break

4.6 SENTENCIA PASS
-------------------
No hace nada. Se usa cuando la sintaxis requiere una sentencia pero no hay acción.
También se usa '...' (Ellipsis) como placeholder alternativo.

4.7 SENTENCIA MATCH (Python 3.10+)
-----------------------------------
Pattern matching — más poderoso que switch/case de C/Java/JS:
  def http_error(status):
      match status:
          case 400: return "Bad request"
          case 404: return "Not found"
          case _:   return "Something's wrong"

Puede combinar literales con '|', hacer unpacking de tuplas/listas,
capturar variables, usar guards 'if', matching de clases.
Referencia: PEP 636 https://peps.python.org/pep-0636/

4.8 DEFINICIÓN DE FUNCIONES
-----------------------------
  def fib(n):
      """Print Fibonacci series less than n."""
      a, b = 0, 1
      while a < n:
          print(a, end=' ')
          a, b = b, a+b

- Keyword 'def' + nombre + parámetros entre ()
- Primera sentencia del cuerpo puede ser un DOCSTRING (triple quotes)
- 'return' sin valor retorna None
- Las funciones son objetos — pueden asignarse a variables

4.9 MÁS SOBRE FUNCIONES
------------------------

4.9.1 Valores por defecto de parámetros:
  def ask_ok(prompt, retries=4, reminder='Please try again!'):

ADVERTENCIA: los valores por defecto se evalúan UNA SOLA VEZ en la definición.
Para mutables, usar None como default:
  def f(a, L=None):
      if L is None: L = []

4.9.2 Keyword arguments (kwarg=value):
  parrot(voltage=1000)
  parrot(voltage=1000, action='VOOOOOM')

4.9.3 Parámetros especiales (Python 3.8+):
  def f(pos1, pos2, /, pos_o_kwd, *, kwd1, kwd2):
  - '/' separa parámetros solo-posicionales de los demás
  - '*' separa parámetros solo-keyword de los posicionales

4.9.4 Listas de argumentos arbitrarios (*args, **kwargs):
  def write_multiple_items(file, separator, *args):
  def f(**kwargs)   # diccionario de keyword args

4.9.6 Expresiones Lambda:
  lambda a, b: a + b
  pairs.sort(key=lambda pair: pair[1])
  Restricción: una sola expresión. Azúcar sintáctica para def.

4.9.7 Docstrings — convenciones:
- Primera línea: resumen conciso. Letra mayúscula, termina en punto.
- Si hay más líneas: segunda línea en blanco, luego párrafos.

4.9.8 Anotaciones de función (type hints — PEP 3107, 484):
  def f(ham: str, eggs: str = 'eggs') -> str:
  Guardadas en __annotations__. No afectan la ejecución.

4.10 ESTILO DE CÓDIGO (PEP 8)
------------------------------
- Indentación: 4 espacios, sin tabs
- Líneas máx 79 caracteres
- Espacios alrededor de operadores: a = f(1, 2) + g(3, 4)
- Clases: UpperCamelCase. Funciones/métodos: lowercase_with_underscores
- UTF-8 por defecto
- Referencia completa: https://peps.python.org/pep-0008/
