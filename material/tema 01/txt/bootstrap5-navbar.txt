Bootstrap 5.3 — Navbar Component
Fuente: https://getbootstrap.com/docs/5.3/components/navbar/
=============================================================

DESCRIPCIÓN
===========
Navbar es el componente de navegación responsive y poderoso de Bootstrap.
Soporta branding, navegación, formularios y más.
Requiere JavaScript (incluido en bootstrap.bundle.min.js) para el collapse.

CÓMO FUNCIONA
=============
- Requiere .navbar con .navbar-expand{-sm|-md|-lg|-xl|-xxl} para collapse responsive
- Fluid por defecto: usar .container para limitar el ancho
- Responsive por defecto (requiere Collapse plugin JS)
- Usar <nav> o role="navigation" para accesibilidad

COMPONENTES SOPORTADOS
======================
.navbar-brand       → Nombre/logo del proyecto
.navbar-nav         → Navegación principal
.navbar-toggler     → Botón hamburguesa para collapse
.navbar-text        → Texto vertical centrado
.collapse.navbar-collapse → Agrupa contenido collapsable

    <a class="navbar-brand" href="#">Mi Blog</a>
  </div>
</nav>

ALINEACIÓN DE LINKS
===================
<!-- Links a la izquierda (default) -->
<ul class="navbar-nav me-auto">...</ul>

<!-- Links a la derecha -->
<ul class="navbar-nav ms-auto">...</ul>

<!-- Links centrados -->
<ul class="navbar-nav mx-auto">...</ul>

INDICAR PÁGINA ACTIVA
=====================
<a class="nav-link active" aria-current="page" href="index.html">Inicio</a>

TEMAS DE COLOR
==============
<!-- Claro (default) -->
<nav class="navbar bg-body-tertiary">...</nav>

<!-- Oscuro -->
<nav class="navbar bg-dark border-bottom border-body" data-bs-theme="dark">
  <!-- Navbar content -->
</nav>

<!-- Color personalizado -->
<nav class="navbar" style="background-color: #e3f2fd;" data-bs-theme="light">
  <!-- Navbar content -->
</nav>

POSICIONAMIENTO
===============
<!-- Fijo arriba -->
<nav class="navbar fixed-top bg-body-tertiary">...</nav>

<!-- Fijo abajo -->
<nav class="navbar fixed-bottom bg-body-tertiary">...</nav>

<!-- Sticky (se queda al llegar al top) -->
<nav class="navbar sticky-top bg-body-tertiary">...</nav>

CLASES CLAVE
============
.navbar                  → Contenedor principal
.navbar-expand-lg        → Expande en pantallas lg+, colapsa en menores
.navbar-brand            → Logo o nombre del sitio
.navbar-toggler          → Botón hamburguesa
.navbar-toggler-icon     → Ícono del botón (lineas horizontales)
.navbar-collapse         → Contenedor del menú collapsable
.collapse                → Estado inicial: colapsado
.navbar-nav              → Lista de navegación
.nav-item                → Ítem de la lista
.nav-link                → Enlace de navegación
.active                  → Indica página actual
.disabled                → Enlace deshabilitado
.me-auto                 → Margin-end: auto (links a la izquierda)
.ms-auto                 → Margin-start: auto (links a la derecha)
