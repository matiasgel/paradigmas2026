NOVEDADES PEDAGÓGICAMENTE RELEVANTES EN PYTHON 3.13
(Lanzado: octubre 2024)
==============================================

RESUMEN EJECUTIVO
-----------------
Python 3.13 es la última versión estable. Las 3 grandes novedades son:
1. Nuevo intérprete interactivo (REPL) mejorado
2. Free-threaded mode experimental (GIL opcional — PEP 703)
3. JIT compiler experimental (PEP 744)

De estas, SOLO el REPL mejorado es pedagógicamente relevante para primer curso.
Las otras dos son avanzadas/experimentales — solo mencionar contextualmente.

=====================
1. REPL INTERACTIVO MEJORADO (⭐⭐⭐ MUY RELEVANTE PARA CLASE)
=====================
- Nuevo intérprete interactivo por defecto (basado en código de PyPy)
- Edición multilínea con preservación de historial
- Soporte directo para comandos REPL: help, exit, quit (sin necesidad de llamarlos como funciones)
- Prompts y tracebacks con COLOR habilitado por defecto
- Ayuda interactiva con F1 y historial de comandos separado
- CTRL+backspace borra palabras completas (como en terminales modernas)

Relevancia pedagógica: El nuevo REPL hace la programación exploratoria más
natural. Los colores en tracebacks ayudan a los estudiantes a identificar
errores más rápidamente.

¿Cómo desactivar colores si es necesario? Variable de entorno NO_COLOR=1

=====================
2. MENSAJES DE ERROR MEJORADOS (⭐⭐⭐ MUY RELEVANTE PARA CLASE)
=====================
- Tracebacks con colores por defecto en terminal
- Sugerencias contextuales: "¿quisiste decir 'maxsplit'?"
  >>> "Better error messages!".split(max_split=1)
  TypeError: split() got an unexpected keyword argument 'max_split'. 
             Did you mean 'maxsplit'?

- Detección de naming conflicts: si el script se llama 'random.py'
  Python ahora muestra mensaje explicando el conflicto con la stdlib.

Relevancia pedagógica: Reduce la fricción para principiantes.
Los mensajes de error contextuales permiten auto-corrección sin necesidad
de buscar en documentación.

=====================
3. TYPE HINTS AVANZADOS (⭐⭐ RELEVANTE — SOLO INTRO EN MÓDULO I)
=====================
- PEP 696: TypeVar, ParamSpec, TypeVarTuple ahora soportan defaults
- PEP 702: warnings.deprecated() — decorador para marcar API deprecated
- PEP 705: typing.ReadOnly — para TypedDict items read-only
- PEP 742: typing.TypeIs — type narrowing más intuitivo

Para Módulo I: solo mencionar que Python 3.13 tiene type hints más ricos.
Los type hints básicos (str, int, list[int], dict[str, float], Optional)
son suficientes para TP2 y todo el Módulo I.

=====================
4. MEJORAS EN STDLIB (REFERENCIA)
=====================
- copy.replace(): método generalizado para copias modificadas de objetos
- dbm.sqlite3: nuevo backend SQLite para dbm (default)
- Módulos eliminados (PEP 594 — "dead batteries"):
  aifc, cgi, cgitb, crypt, imghdr, mailcap, nis, nntplib, pipes, 
  sndhdr, sunau, telnetlib, uu, xdrlib
  → VERIFICAR que ningún ejercicio use estos módulos

=====================
5. CAMBIOS QUE AFECTAN EL CURSO
=====================
- datetime.utcnow() DEPRECADO → usar datetime.now(tz=datetime.UTC)
- Módulos obsoletos eliminados (ver lista arriba)
- Anotaciones de tipo más estrictas en futuras versiones
